======================================
Chrome Web Store 隱私權實務規範說明（v2.3）
======================================

【單一用途說明 (Single Purpose)】

本擴充功能的單一用途為：優化陽明交通大學（NYCU）E3 學習平台的使用體驗。

主要功能包括：
- 作業截止時間倒數、管理與提醒
- 課程公告與信件整合
- 成績查詢
- 教材下載與 ZIP 批次下載
- 背景同步與桌面通知
- 繁體中文 / English 介面與外觀設定
- 選配的 AI 摘要、每日總覽與翻譯

上述功能均直接服務於 E3 課程資訊的查看、整理、提醒與處理，不涉及廣告、追蹤、資料轉售或其他無關用途。

--------------------------------------

【storage 權限說明】

權限名稱：storage

使用理由：
用於在使用者瀏覽器本機儲存擴充功能運作所需資料，包括：

1. 作業列表、截止時間與手動作業
2. 課程列表與名稱
3. 公告、信件與其快取
4. 成績與同步狀態
5. 已繳交 / 已讀等使用者狀態
6. 語言、外觀、通知與提醒設定
7. 使用者自行提供的 Gemini / OpenAI API Key 與模型設定
8. AI 每日總覽快取與來源資訊
9. 通知去重 / 排程狀態及有限量診斷日誌

技術實作：
使用 chrome.storage.local API。資料主要保留在使用者本機瀏覽器；解除安裝擴充功能或清除擴充功能資料後可移除。

--------------------------------------

【alarms 權限說明】

權限名稱：alarms

使用理由：
用於排程背景工作，例如：
- 定期同步 E3 作業 / 課程資料
- 在已有 E3 分頁時同步公告與信件
- 檢查參與者或其他需要定期更新的資料
- 排程並重新檢查作業截止提醒與桌面通知

定時工作不會為了公告 / 信件同步自行開啟 E3 登入分頁；沒有可用的 E3 分頁時會跳過該次同步。

--------------------------------------

【downloads 權限說明】

權限名稱：downloads

使用理由：
用於教材與附件下載。使用者可下載單一 E3 檔案，或由擴充功能將多個教材以 JSZip 打包成 ZIP 後下載。

安全限制：
- 只允許由 https://e3.nycu.edu.tw/ 或 https://e3p.nycu.edu.tw/ 啟動的 E3 下載 URL
- 會檢查重新導向後的 finalUrl；若離開允許的 E3 HTTPS 主機會取消下載並嘗試移除檔案
- 下載檔名會拒絕路徑遍歷字元

--------------------------------------

【notifications 權限說明】

權限名稱：notifications

使用理由：
用於顯示使用者可自訂的桌面通知，例如新公告 / 信件、評分或作業截止提醒。使用者可在設定中關閉桌面通知、調整通知方式與設定多個截止提醒時距。

通知只使用 E3 Helper 已同步或由使用者建立的課程 / 作業資料，不用於廣告或行銷。

--------------------------------------

【網站存取權限說明】

1. host_permissions: "https://e3.nycu.edu.tw/*"
   用途：存取 NYCU E3 官方 HTTPS 內容與 API，包括作業、課程、公告、成績、附件等核心功能。

2. host_permissions: "https://e3p.nycu.edu.tw/*"
   用途：存取 NYCU E3+ 官方 HTTPS 內容與 API，支援現行 E3 服務。

3. host_permissions: "https://generativelanguage.googleapis.com/*"
   用途：只有在使用者選擇 Gemini 作為 AI 摘要供應商並啟用相關功能時，將必要文字送往 Google Gemini API。

4. host_permissions: "https://api.openai.com/*"
   用途：只有在使用者選擇 OpenAI 作為 AI 摘要供應商並啟用相關功能時，將必要文字送往 OpenAI API。Responses API 請求使用 store:false。

5. host_permissions: "https://translate.googleapis.com/*"
   用途：使用翻譯功能時，將待翻譯文字送往 Google Translate API。翻譯功能與 Gemini / OpenAI 摘要供應商分離。

6. content_scripts matches: "<all_urls>"
   用途：讓使用者可在一般網頁上開啟 E3 Helper 側邊欄並查看已同步的作業、公告、成績等資訊，而不必先切回 E3 網站。

   限制：
   - 在非 E3 網站上，擴充功能會插入自己的側邊欄 / 浮動按鈕 UI
   - 不會把非 E3 網頁內容收集或傳送到專案伺服器、AI 供應商或翻譯服務
   - E3 專用的頁面解析 / 同步邏輯只在 E3 網站使用

--------------------------------------

【第三方服務與資料傳輸】

核心 E3 功能不經過本專案自建伺服器；資料直接在瀏覽器與 NYCU E3 官方主機之間傳輸。

選配功能可能使用以下第三方服務：

1. Google Gemini
   - 網域：generativelanguage.googleapis.com
   - 傳輸時機：使用者選擇 Gemini 並要求 AI 摘要 / 每日總覽時
   - 傳輸內容：完成該功能所需的公告 / 信件等文字與提示內容，以及使用者提供的 API Key 作為驗證資訊

2. OpenAI
   - 網域：api.openai.com
   - 傳輸時機：使用者選擇 OpenAI 並要求 AI 摘要 / 每日總覽時
   - 傳輸內容：完成該功能所需的公告 / 信件等文字與提示內容，以及使用者提供的 API Key 作為驗證資訊
   - Requests API 設定：store:false

3. Google Translate
   - 網域：translate.googleapis.com
   - 傳輸時機：使用者執行翻譯功能時
   - 傳輸內容：待翻譯的文字

本專案沒有自建後端伺服器接收上述內容，也不販售資料、不用於廣告、不建立跨網站瀏覽或使用者行為追蹤資料。

【遠端程式碼說明】

本擴充功能套件內含：

1. JSZip（jszip.min.js）
   - 版本：3.10.1
   - 上游：https://github.com/Stuk/jszip
   - 用途：在本機將多個教材檔案打包成 ZIP
   - 授權：MIT License
   - 函式庫直接包含在擴充功能套件內，不從遠端載入或執行

本擴充功能不透過 CDN、API 回應或其他遠端位置下載並執行 JavaScript / WebAssembly 等程式碼。Gemini、OpenAI 與 Google Translate 僅作為資料 API 使用，其回應不會被當成可執行程式碼載入。

--------------------------------------

【資料處理說明】

可能處理的資料包括：

1. 課程與作業資料（課程名稱、作業標題、截止時間、URL、狀態）
2. 公告與信件（標題、內容、發布時間、來源連結）
3. 成績資料
4. 使用者自行建立的作業與狀態
5. 語言、外觀、通知等偏好設定
6. 使用者自行提供的 Gemini / OpenAI API Key
7. AI 摘要 / 每日總覽的本機快取與來源資訊
8. 擴充功能診斷日誌（有限量保留於 chrome.storage.local）

E3 登入由 NYCU 官方網站處理。擴充功能可能使用瀏覽器既有的 E3 登入工作階段向 E3 發出請求，但不要求、收集或儲存使用者的 NYCU 密碼。

--------------------------------------

【資料使用與隱私保證】

- 不販售使用者資料
- 不將資料用於廣告、信用評分、保險、放款或與 E3 Helper 功能無關的用途
- 不建立跨網站瀏覽追蹤紀錄
- 不使用非 E3 網站內容作為 AI / 翻譯輸入
- API Key 僅儲存在使用者本機，並只傳給使用者選擇的對應 API 供應商作驗證
- 第三方 API 的資料處理另受各供應商自身服務條款與隱私政策規範
- 使用者可停用 AI / 通知功能，並可清除擴充功能本機資料

GitHub 專案：https://github.com/NYCU-Chung/portal_e3_helper

--------------------------------------

【選用 scripting 與一般 HTTP／HTTPS 網站存取權】

「在所有網站顯示浮動按鈕」預設關閉。僅使用者開啟時申請 scripting 與 http://*/*、https://*/* 的選用權限，用於在一般網站顯示 E3 Helper 浮動按鈕與已同步課業資訊；不在一般網站收集 E3 作業，不因開啟側欄自動打開 E3。Chrome 內部頁面與商店等受限制頁面不支援。關閉時隱藏已載入的介面並取消未來注入；原有校內網站保留原本行為。一般網站頁面內容不會因開啟此功能而被傳送給 AI 或其他服務。

全網站模式的網頁只載入封閉 Shadow DOM 按鈕。點擊後才建立擴充功能來源的 iframe，作業與 API Key 不放入第三方網站 DOM；網頁不得透過跨來源存取或訊息讀取。關閉功能移除整個面板與按鈕並撤銷廣泛選用網站權限，且不再注入。
